PERNYATAAN / DISCLAIMER

Ini proyek hobi eksperimental, gratis, dan tanpa jaminan apa pun. Pemasang ini
mengubah pengaturan sistem: membuka Windows Firewall untuk tsunagupad.exe dan
uxplay.exe (hanya dari subnet lokal dan Tailscale), dan bila dipilih memasang
driver layar virtual, sebuah layanan Windows, serta menambahkan folder program
ke PATH. Siapa pun yang memegang kode akses (QR) dapat melihat dan
mengendalikan layar komputer ini, jadi jangan bagikan kode itu. Gunakan di
jaringan milik Anda sendiri dengan kata sandi Wi-Fi yang kuat.

This is an experimental hobby project provided free of charge and without any
warranty. The installer changes system settings: it opens Windows Firewall for
tsunagupad.exe and uxplay.exe (local subnet and Tailscale only), and, when
selected, installs a virtual display driver, a Windows service, and adds the
program folder to PATH. Anyone holding the access key (QR code) can see and
control this computer's screen, so do not share it.
