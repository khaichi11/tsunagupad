DISCLAIMER

This is an experimental hobby project provided free of charge and without any
warranty. The installer changes system settings: it opens Windows Firewall for
tsunagupad.exe and uxplay.exe (local subnet and Tailscale only), and, when
selected:

- installs Tsunagu-Pad's own second screen driver. It runs in user mode, not
  in the kernel. It is signed on this computer with a one-time certificate
  whose private key is deleted right away, and that certificate is removed
  again when Tsunagu-Pad is uninstalled;
- installs a Windows service;
- adds the tsunagupad command to PATH.

Anyone holding the access key (QR code) can see and control this computer's
screen, so do not share it. Use it on your own network with a strong Wi-Fi
password.
